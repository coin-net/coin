## Official Communication & Security

In the spirit of true anonymity, **Coin has no official social media accounts, groups, or servers.** Any Discord, Telegram, Facebook, Reddit, or other account claiming to officially represent Coin is not affiliated with the development team. **Beware of impersonators and scams.**

Users, miners, and holders are free to organize and build communities as they wish.

All official announcements, software releases, and development updates will be published exclusively through the official Coin website.

**Official Website:** https://coinnet.org  
**Blockchain Explorer:** https://coinnet.org/explorer/

The Coin development team will **never** contact you requesting wallet passwords, recovery seed phrases, private keys, or wallet balances.

## Network Configuration

Coin Mainnet uses the following default ports:

- **P2P:** `38880/TCP`
- **RPC:** `38881/TCP`

The P2P port enables communication between network nodes. The RPC port provides access to the Coin daemon and should not be exposed to untrusted networks.
